## Acceptance is about the explanatory result

The [ticket](https://github.com/MECHLESIA/codegraph/issues/47) requires artifact-bound, decision-useful active/quiet attribution, fixed work/results, explicit owner/counter limits, independent review and map-driver acceptance. It permits a bounded negative result with a precise remainder. Exact request counts, trial names, a particular profiler or archive format are chosen mechanics, not additional universal completion requirements. An unavailable optional diagnostic does not make all other evidence invalid; a missing material discriminator must still remain visible beside the affected claim.
